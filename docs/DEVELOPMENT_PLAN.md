# 八阶段开发计划

以 PRODUCT_SPEC.md 为准。严格串行，阶段 n 依赖先前阶段；仅当用户明确继续时进入下一阶段。每阶段更新必要文档、完成提交、按授权推送 main、如实报告后停止。任何阶段均遵守云端禁编译/测试，每阶段最多一次 git diff --check。

## 阶段 1：项目初始化与架构

状态：源码交付完成，未编译。
任务：检查仓库/分支/Git；新建或整理 Android 工程；配置 Kotlin/Compose/Material 3、min/target SDK、Kotlin DSL；基础目录与接口；六份文档；记录工具依赖与决策。不接入假 FFmpeg，不提前 UI 实现。
验收：结构和 Gradle 配置完整，UI/业务职责清晰，文档明确，不声称编译通过。

## 阶段 2：UI 与导航

状态：源码交付完成，未编译；UI 已接线，真实媒体功能按后续阶段禁用。依赖：阶段 1。
任务：卡片首页、四底栏、视频转换页、剪辑工作区、全屏按钮式裁剪器、成果库、导出 Bottom Sheet；空/错误状态、基础交互、系统返回与底栏隐藏逻辑；共用模块状态，不堆长页。
验收：卡片和底栏路由一致；常用操作合理；列表滚动和固定操作；未完成音频不显示假成功。

## 阶段 3：文件导入与持久化

状态：源码交付完成，未编译/设备验证。依赖：阶段 2。
任务：Photo Picker 视频单多选、SAF 文件单多选；真实视频/歌曲列表、重复项处理；拖柄排序、边缘滚动、取消恢复、上下移；最近项目自动存取；URI 持久权限与受控副本；成果元数据；引用安全生命周期。
验收：真实文件可加入、重复合理；切页不丢列表；项目保存恢复；无失控复制或引用误删。

## 阶段 4：音频试听与编辑模型

状态：源码完成（含真实Media3与持久化编辑），未编译/设备验证。依赖：阶段 3。
任务：Media3 播放暂停/跳转；标记开始不中断，结束自动暂停；删除选区后合拢、暂停于接缝；撤销重做、分割、恢复、仅保留；原曲/片段顺序试听、接缝试听；数字时间、±0.1 秒和当前位置设边界；保存编辑。
验收：不改源文件，时间映射正确，跨段多次删除可继续，重开数据保留，预览真实。明确预览与最终编码的精度限制。

## 阶段 5：FFmpeg、LAME、JNI 与波形

状态：源码完成，未进行原生/Android编译、ELF/APK或设备验证。依赖：阶段 4。
任务：固定 FFmpeg/LAME 源版本和完整性信息；精简 NDK 构建脚本/JNI；进度取消；真实探测、峰值/RMS、多分辨率波形、Compose 绘制、缩放平移定位、删除后合拢；16 KB ELF/打包兼容；许可。
验收：源码获取/固定信息和构建脚本齐全，无假 .so，波形真实且后台分析；可解释依赖/构建；明确原生代码未经本地编译。云端不执行脚本。

## 阶段 6：真实转换与拼接导出

状态：源码完成（含真实转换、片段渲染、双遍响度、验证登记和取消），未编译/设备验证。依赖：阶段 5。
任务：视频至 LAME MP3，满足条件的 MP3 流复制；批量转换、单文件与整体进度、取消/重试；非破坏片段渲染、多曲与单曲 MP3；每歌 loudnorm 正确分析/处理、默认开；导出进度、失败处理和临时清理。
验收：真实媒体路径，无模拟；多曲多片段正确；失败无假成果；取消清不完整文件保留成功文件；设备未验证如实声明。

## 阶段 7：成果库与 U 盘另存

状态：未开始。依赖：阶段 6。
任务：真实成果原子入库、分类、试听、改名、分享、加入拼接、外部 SAF 复制/U盘选位置、最近授权位置、删除、项目引用保护与无用文件清理；完成面板保留当前模块。
验收：实体存在才入库；外存复制、不覆盖；删内部不影响外部；项目引用安全；失败/取消不丢已有成果。

## 阶段 8：集成、反馈修复与交付

状态：未开始。依赖：阶段 7 和用户实际本地反馈。
任务：检查 UI/业务连接，针对本地错误修权限/播放器边界/原生兼容；明确错误提示；清无用代码、完善构建与最终状态。禁止云端大规模测试。
验收：所有要求有真实实现，无假成功；文件引用完整；源码/NDK脚本/使用说明齐全；用户设备验证结果如实记录，未验证不可宣称通过。

## 阶段 3 后独立 UI 专项（用户另行授权）

范围：统一设计系统、图标、首页/视频/剪辑/裁剪/成果/Bottom Sheet/底栏的视觉和分区布局，关闭页面默认过渡。保留既有业务和功能开放状态，不推进阶段4。
状态：源码完成，未编译/设备验证；静态检查和交付记录见 IMPLEMENTATION_STATUS / LOCAL_VALIDATION。完成提交推送后停止。

## 第二轮 UI 精修（阶段3后的独立交付）

用户按上一轮实机反馈授权：先拆裁剪空/加载/有歌曲状态，再压缩视频项、单文件命名面板、成果空态和全局密度。只完成UI，B–E阶段呈现须由未来真实事件驱动，不能冒充阶段4完成。提交推送后停止。当前源码完成，检查记录见 LOCAL_VALIDATION；本轮未编译/设备验证。

## 阶段4附加授权：重写短动画

用户反馈上一轮即时切换后图标卡顿，允许参考官方方案重写。加入短淡化及固定图标的底栏颜色反馈、图标一次构建/预热；不增加复杂入场或弹簧，不升级Navigation3。属于本阶段交付，不推进阶段5。

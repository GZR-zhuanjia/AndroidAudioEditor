# 本地构建与验证记录

## 云端约束

本会话不运行 Gradle（包括 build、assemble、test、lint）、Android、NDK/CMake 编译、模拟器或等效验证，不为测试装 SDK/NDK，不下载大型依赖。源码审阅不能替代编译和设备验证。

## 用户本地准备与构建（仅用户执行）

1. 克隆本仓库，Android Studio 打开项目根目录；使用支持 AGP 8.10 的稳定版（Meerkat Feature Drop 2024.3.2 或兼容更新版本），Gradle JDK 17。
2. 本地安装 Android SDK Platform 36，使用项目 Wrapper 8.11.1；Android Studio 配置本机 SDK 路径，local.properties 不提交。首次同步需要用户本地网络下载依赖，应用运行本身无网络需求。
3. 用 Android Studio Sync 后 Build APK；也可用户本地执行 `./gradlew :app:assembleDebug`（Windows 为 `gradlew.bat :app:assembleDebug`）。此命令未由云端执行。
4. 当前无需 NDK/CMake，无 FFmpeg 或任何 .so；阶段 5 后更新原生构建步骤。
5. 将完整首个错误及相关文件行号反馈，按具体错误修复，不展开无关测试。不要上传签名密钥或凭据。

阶段 3 已接真实导入/排序/持久化源码，音频处理仍未开放；下面阶段 2 记录为当时版本说明，当前应按阶段 3 场景检查。API 36 边到边与窗口 Insets 仍待实际设备检查。若同包名旧应用已装，先保护原数据；当前新项目不含旧数据迁移或版本更新保证。

## 阶段 3：建议本地验证（全部未执行）

先在 Android Studio 同步并构建，反馈第一个具体错误；云端未运行下列场景。无 NDK/FFmpeg 依赖新增。

1. Photo Picker 只显示视频，选一项和多项；SAF 多选视频，再次从另一入口继续追加；取消选择不改队列，切底栏/旋转列表保留，移除有效；不申请整个相册权限。
2. SAF 多选歌曲，真实名称/时长加入卡片；同 URI 重选跳过；不同目录同名文件保留为不同歌曲；不支持格式/无时长/文件已删除要显示失败，不生成假片段。不同 provider 的相同内容 URI 可能被当作独立来源。
3. 上移/下移边界正确；长按左柄跨多首排序，靠顶部/底部连续滚动，松手写入；取消按钮、系统返回、系统取消指针和旋转时恢复原序；拖动期间底栏禁切。短列表、长列表、长文件名、小屏都需检查。
4. 修改导出名和响度开关，等待保存提示结束；退出再开恢复歌曲顺序、来源、片段和设置，首页可继续；视频队列在新进程不恢复（设计如此）。
5. 持久读授权 provider 重开仍可读；撤销权限/移动文件/U盘断开保留歌曲并标不可用；重新检查、重新选择同一原曲恢复；新选择文件短于已有片段范围应拒绝且不丢旧片段。
6. 不能持久授权的 provider 才建立受控内部副本，复制完成前取消/失败/空间不足不登记歌曲；重复导入不反复复制；移除最后项目引用后回收该副本。源文件和外部副本不受影响。
7. 使用本地调试数据副本检查损坏/未知版本 JSON：提示具体读取问题，禁止覆盖/清理；不要用唯一重要数据做破坏性验证。片段边界/来源/规范路径校验应拒绝不一致快照。
8. 构造中断复制后的无引用受控 .part/.source 后，下一次有效加载只清无引用文件，不能删仍由项目/成果索引引用的实体。成果真实生成后才能验证删除成果与项目引用交叉情形，当前不造假成果。
9. 保存失败应提示、顺序回到已提交状态；保存中立即终止进程允许未提交操作丢失，但已提交快照不应被替换为坏数据。初始化期间恢复系统选择器结果不能静默丢失选择。
10. 播放/剪切/转换/导出仍应禁用，导入歌曲不进入成果库，没有假成功面板或假波形。

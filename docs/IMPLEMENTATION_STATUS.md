- JNI新增转换/滤镜接口未经编译；FFmpeg graph协商、loudnorm首尾样本数、LAME标签和MP3时长须本地确认。只写源码不代表转换或均衡已设备验收。
- 拼接PCM约384KB/秒，预估需要全部PCM+均衡时最大单曲额外PCM+MP3+32MiB；空间不足明确失败，写入途中不足也会失败清理。文件系统清理失败会提示并下次有效加载重试，不保证异常存储立即清净。
- 渲染/导出时间线最多24小时、最多4096首/每曲100000片段，源最多32声道/384kHz；波形仍最多8小时。采样网格48kHz、原曲时间边界向上取整；容器尾padding最多100ms差异允许保留实际采样而略缩短，更大缺口失败，不伪造尾音。loudnorm长度不一致拒绝提交。
- 原生首次本地构建可能遇NDK/libtool/FFmpeg配置或JNI/API问题；所有源码未编译。8小时/32声道/384kHz为明确上限，长音频CPU/内存仍待设备验证；只编入列表内格式。
- provider非seek源可能不支持相关容器；取消不能保证立刻打断provider阻塞pread。约20ms波形边界不等同采样级裁切，高倍缩放不产生新细节；FFmpeg PTS/priming与Media3可能不同。缓存键不是全文件哈希，源修改但元数据不变可能复用旧缓存。
- Media3片段配置为微秒，播放头/seek API为毫秒，标记读取真实毫秒位置；FFmpeg PTS/解码延迟、48kHz网格和MP3编码补偿可能与预览不同，不能声称逐采样一致或设备绝对无缝；普通预览未做响度均衡。
- 非破坏性数据重开可还原，最多保留50步撤销/重做，删除内容记录另存；未结束标记和试听模式是会话状态，重开回到编辑结果暂停，不恢复播放任务。

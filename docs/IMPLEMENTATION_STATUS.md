## 限制与风险

- 本轮未运行Gradle/Android/NDK/CMake构建、测试、模拟器、性能分析；未安装SDK/NDK/大依赖、未执行原生脚本。本阶段只源码/API/资源引用与差异静态审阅；唯一git diff --check退出码0，无空白错误，未重复执行，记录见LOCAL_VALIDATION。
- SAF/provider行为、FileProvider临时授权、Media3成品时长与生命周期、API/Compose类型均未编译/实机验证。目录读取/创建/回读各可能失败，不能承诺直接写未经授权目录或所有provider完全相同；目录超过100000项拒绝。
- 外部复制回读增加I/O耗时；阻塞provider读取/写入可能延迟取消。拔盘时本次新文件可能清不掉，明确提示手动检查，内部成果不丢；核对完成不代表物理介质永远抗断电。
- 分享快照是临时cache、按24小时阈值机会清理，系统可提前回收；长期交付用另存。旧版未跟踪授权不撤销，树授权对同authority有效来源保守保留，不能声称所有孤立授权都已回收。没有后台清理/恢复任务。
- JNI新增转换/滤镜接口未经编译；FFmpeg graph协商、loudnorm首尾样本数、LAME标签和MP3时长须本地确认。只写源码不代表转换或均衡已设备验收。
- 拼接PCM约384KB/秒，预估需要全部PCM+均衡时最大单曲额外PCM+MP3+32MiB；空间不足明确失败，写入途中不足也会失败清理。文件系统清理失败会提示并下次有效加载重试，不保证异常存储立即清净。
- 渲染/导出时间线最多24小时、最多4096首/每曲100000片段，源最多32声道/384kHz；波形仍最多8小时。采样网格48kHz、原曲时间边界向上取整；容器尾padding最多100ms差异允许保留实际采样而略缩短，更大缺口失败，不伪造尾音。loudnorm长度不一致拒绝提交。
- 原生首次本地构建可能遇NDK/libtool/FFmpeg配置或JNI/API问题；所有源码未编译。8小时/32声道/384kHz为明确上限，长音频CPU/内存仍待设备验证；只编入列表内格式。
- provider非seek源可能不支持相关容器；取消不能保证立刻打断provider阻塞pread。约20ms波形边界不等同采样级裁切，高倍缩放不产生新细节；FFmpeg PTS/priming与Media3可能不同。缓存键不是全文件哈希，源修改但元数据不变可能复用旧缓存。
- Media3片段配置为微秒，播放头/seek API为毫秒，标记读取真实毫秒位置；FFmpeg PTS/解码延迟、48kHz网格和MP3编码补偿可能与预览不同，不能声称逐采样一致或设备绝对无缝；普通预览未做响度均衡。
- 非破坏性数据重开可还原，最多保留50步撤销/重做，删除内容记录另存；未结束标记和试听模式是会话状态，重开回到编辑结果暂停，不恢复播放任务。
- 新字段为schema1兼容默认值，旧数据可读取；旧版应用不认识新字段，回退旧APK不保证可读，不能直接覆盖数据。历史/删除区间同样受来源和时间范围校验。
- 返回/编辑已接保存失败反馈，瞬间杀进程仍可能丢未提交动作；已提交快照应保留。文件/格式错误只报错，不用整原曲或伪音频兜底。
- 动画卡顿根因未通过性能追踪证实。当前改动针对重复解析、立即切页与叠加动画/广域重组等可能因素；实际帧率和图标表现待用户本地确认。
- 引用保护含项目/成果/活动访问；URI/临时文件回收按上述范围，不删除外部原曲/另存副本。schema1未增字段，最近目录和授权账本是小型私有偏好；旧工程迁移与旧APK回退仍无保证。

## 部分完成 / 当前限制

上述代码已连接，但真实导入、重启恢复与拖动没有编译或设备结果。系统媒体解析受 Android 平台格式支持限制；当前不借助 FFmpeg 兜底。重复依据 URI，不跨 provider 对同内容做哈希合并。

成果索引无真实生产者，所以成果库仍为空，加入成果的路径无法在当前正常 UI 中做端到端验证；成果生成/删除/另存均待后续。当前没有编辑操作生产者，保存/恢复的是现有片段结构，不能声称多次剪切已经验证。

设置逐次排队自动保存；显示保存中时突然杀进程可能丢未落盘操作，原已提交快照仍保留。损坏/未知 schema 停止写入、保留数据，不提供“重置为默认”覆盖按钮。保留的视频 URI 不保证跨进程有效，视频队列不恢复。

内部清理只覆盖 sources/ 下受控无引用 .part/.source，不清 results/。URI 授权共用或获取后突然退出时可能保守保留无引用读授权，后续阶段 7 完善授权账本；不破坏仍使用文件的授权。尚无后台音频任务，不承诺任务引用/临时处理文件清理已完成。

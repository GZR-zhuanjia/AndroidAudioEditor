## 限制与风险

- 未运行任何Gradle/Android/NDK/CMake构建、测试、模拟器、性能分析；未安装SDK/NDK或大依赖、未执行原生获取/构建/ELF脚本。API/类型只静态审阅；本阶段唯一git diff --check退出码2，指出上游LAME许可第5行空格/Tab缩进；已仅规范许可文本空白，未重复执行，记录见LOCAL_VALIDATION。
- 原生首次本地构建可能遇NDK/libtool/FFmpeg配置或JNI/API问题；所有源码未编译。8小时/32声道/384kHz为明确上限，长音频CPU/内存仍待设备验证；只编入列表内格式。
- provider非seek源可能不支持相关容器；取消不能保证立刻打断provider阻塞pread。约20ms波形边界不等同采样级裁切，高倍缩放不产生新细节；FFmpeg PTS/priming与Media3可能不同。缓存键不是全文件哈希，源修改但元数据不变可能复用旧缓存。
- Media3片段配置为微秒，播放头/seek API为毫秒，标记读取真实毫秒位置；不同格式、编码延迟/补偿和解码器可能导致接缝听感与最终MP3不完全一致，不能声称设备上绝对无缝。正式MP3尚无实现，预览未做响度均衡。
- 非破坏性数据重开可还原，最多保留50步撤销/重做，删除内容记录另存；未结束标记和试听模式是会话状态，重开回到编辑结果暂停，不恢复播放任务。
- 新字段为schema1兼容默认值，旧数据可读取；旧版应用不认识新字段，回退旧APK不保证可读，不能直接覆盖数据。历史/删除区间同样受来源和时间范围校验。
- 返回/编辑已接保存失败反馈，瞬间杀进程仍可能丢未提交动作；已提交快照应保留。文件/格式错误只报错，不用整原曲或伪音频兜底。
- 动画卡顿根因未通过性能追踪证实。当前改动针对重复解析、立即切页与叠加动画/广域重组等可能因素；实际帧率和图标表现待用户本地确认。
- 文件引用保护沿用项目/成果索引；本轮只读分析持有fd且退出取消，缓存与原曲隔离。阶段6导出任务必须扩展活动引用保护。URI授权保守保留等阶段3限制仍存在。
